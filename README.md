# FruFlaFloo

Набор **HTML**-шаблонов для создания визуализаций. Каждый шаблон - это автономная страница с анимацией, стилизацией под CRT-монитор / эффектом печатающегося текста.

Все шаблоны адаптированы под **PC** и **Mobile**, корректно работают в горизонтальном формате **16:9** для длинных **YouTube**-роликов и в вертикальном **9:16** для **Shorts**. Один и тот же `index.html` подстраивается под экран: меняются масштаб, компоновка, размеры шрифтов и отступы.

## Визуализации

* **Background** - стилизация под CRT-монитор.
* **Chat** - анимированная переписка с эффектом набора текста, аватарками и автопрокруткой.
* **Flow** - поочередное появление окон (блок-схема) с текстом и анимированными стрелками между ними.
* **Folder** - каталог папок и файлов с анимацией и подсветкой элементов.
* **Glitch Loop** - глитч-петля для ascii-графики.
* **Terminal** - терминал с нумерацией строк, мигающим курсором и подсветкой синтаксиса.
* **Terminal - Row selection** - терминал с подсветкой синтаксиса и выделением конкретных строк.
* **Terminal - Screen** - минималистичный экран терминала без подсветки, автоподбор размера шрифта.
* **Terminals** - до 4-х терминалов одновременно: нумерация строк, мигающий курсор и подсветка синтаксиса.
* **Transfer** - передача файлов между двумя пк: вылет, полет по дуге и приземление.

## Как использовать

1. Открой нужный `index.html` в браузере
2. Отредактируй `data.js` с нужными данными
3. Обнови страницу (F5)
4. Запиши экран через любой инструмент для записи экрана
5. Используй в своем ролике

*Во всех шаблонах работает пропуск анимации - достаточно кликнуть мышкой или нажать любую клавишу, если нужно быстро перейти к концу анимации.*
